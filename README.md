# DESCRIPCIÓN DE FUNCIONALIDADES DEL SISTEMA

## 1. Inicio

Pantalla principal del sistema.

Funciones:
- Navegación rápida
- Acceso a módulos
- Dashboard visual

---

## 2. Módulo de Alumnos

Permite administrar toda la información de estudiantes.

Funciones:
- Crear alumnos
- Editar alumnos
- Eliminar alumnos
- Ver detalles
- Buscar dinámicamente
- Filtrar por grado

---

## 3. Módulo de Materias

Administra las materias impartidas.

Funciones:
- Registrar materias
- Asignar docentes
- Editar información
- Eliminar materias

---

## 4. Módulo de Expedientes

Núcleo principal del sistema.

Funciones:
- Relacionar alumnos con materias
- Registrar notas finales
- Registrar observaciones
- Consultar historial académico

---

## 5. Módulo de Reportes

Genera estadísticas académicas.

Funciones:
- Calcular promedios
- Mostrar tabla resumen
- Visualizar gráfica estadística

---

## 6. Búsqueda Dinámica

Permite buscar registros instantáneamente sin recargar la página.

Implementado en:
- Alumnos
- Expedientes

---

## 7. Filtros

Permite filtrar alumnos por grado académico.

---

## 8. Validaciones

El sistema protege:
- integridad de datos
- relaciones entre tablas
- eliminación incorrecta de registros

---

## 9. Interfaz Moderna

Incluye:
- Bootstrap 5
- Bootstrap Icons
- Cards
- Tablas modernas
- Diseño responsive
- Gráficas dinámicas
